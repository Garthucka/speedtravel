# SpeedTravel — ход и скорость выключателя

Отдельная программа, выделенная из BreakerDiag. Расчёт хода и скорости (core/data.py, velocity_events.py,
event_sampling.py) совпадает с BreakerDiag; нейросеть не используется, torch не нужен.

Запуск (Windows, Python 3.10+ с Tcl/Tk): install.bat один раз, затем run.bat.
Или: python -m pip install -r requirements.txt && python main.py

1. «Выбрать папку…» — загружаются все *.csv, слева список с итогами (Vmax, ход, длительность).
2. Клик/стрелки — переключение замеров; графики: ход, скорость, контакты A/B/C.
3. Ctrl/Shift — отметить замеры; «Сохранить отмеченные…» копирует исходный CSV, пишет *_speed.csv, PNG
   и общий summary.csv. «Таблица итогов (все)…» — summary по всей папке.
4. Новый формат CSV: окно сопоставления каналов (запоминается по сигнатуре заголовка,
   %LOCALAPPDATA%\SpeedTravel\mappings.json).

Ограничения: единицы скорости м/с (мм/мс); угловые датчики нужно калибровать (коэфф. → мм);
«Конец движения» определяется по выходу хода в полосу 1% полного хода от конечного значения.
